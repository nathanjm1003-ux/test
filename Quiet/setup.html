Quiet Setup

Getting the app signed, installed and wired to a bare home screen. Three places, in order: the developer portal, your Mac, then the phone itself.

Your identifiers

Fill these in once and every command and identifier below updates to match. Nothing leaves this page.

Developer portal

Identifiers and capabilities

At developer.apple.com → Certificates, Identifiers & Profiles. Six targets means six App IDs.

Identifiers → + → App IDs → App. Register each of these:


      

    

  


  

    
    

      
      

        
Edit each App ID and tick both capabilities. All six need both — including the widget one, because the Control Center toggle writes Screen Time settings directly.

        
Family Controls is a restricted entitlement. Development builds work on a paid account right away. Shipping to TestFlight or the App Store needs a separate approval request to Apple, linked from the capability in the portal. Start that early if you plan to distribute — it is a human review.

      

    

  


  

    
    

      
      

        
Identifiers → App Groups → +, then go back to each App ID and select this group under App Groups → Configure.

        

        
This group is the only channel between the app and its extensions. Miss it on one target and that extension silently reads empty settings.

      

    

  







  

    Your Mac
    
Generate and sign

  

  
Terminal, then Xcode. The project is generated from project.yml rather than checked in, so the first step is XcodeGen.


  

    
    

      
      

        
brew install xcodegen

      

    

  


  

    
    

      
      

        
From the Quiet/ directory. This rewrites the bundle prefix, App Group and team across the spec, the entitlements files and the Swift source.

        

      

    

  


  

    
    

      
      

        
Six targets, each needing the same three things. Xcode will not warn you if an extension is missing one — it will just misbehave at runtime.

        
    
          
  • Team set
    • 
          
  • App Groups ticked, pointing at your group
    • 
          
  • Family Controls present
    • 
        

      

    

  


  

    
    

      
      

        
Not the Simulator. The UI renders there, but authorization fails, no shield ever appears, and no schedule ever fires — so a clean Simulator run tells you almost nothing.

    On the phone
    
Set up the quiet phone

  

  
Everything from here happens on the iPhone itself. Keep this page open on it.


  

    
    

      
      

        
Walk through onboarding and tap Grant Screen Time access. If the sheet refuses, the app prints why rather than failing silently.

      

    

  


  

    
    

      
      

        
    
          
  • Essential — always allowed, even in dumb-phone mode
    • 
          
  • Distracting — allowed, behind a delay and a daily limit
    • 
          
  • Hidden — always shielded, no way through
    • 
        

        
Put Phone, Messages and Maps in Essential now. Quiet cannot add them for you — app identities only come out of the system picker, so there is no way for code to name them. Phone and Settings are not shieldable by Screen Time anyway, but Messages and Maps are, and dumb-phone mode will shield them if you leave them out.

      

    

  


  

    
    

      
      

        
Settings → Home screen rows. Up to eight. Add the usual suspects fills in Apple's own schemes, which are documented and stable.

        
For third-party apps, build a shortcut rather than guessing a scheme:

        
    
          
  • Shortcuts → new shortcut → one action, Open App → pick the app
    • 
          
  • Name it, e.g. Open Spotify
    • 
          
  • Back in Quiet, set that row's URL to:
    • 
        

        
shortcuts://run-shortcut?name=Open%20Spotify

        
Leave Direct launch off. WidgetKit documents widget links as opening the containing app, so a raw spotify:// may do nothing. Off, the row opens Quiet and it forwards — one frame of Quiet, but it works.

      

    

  


  

    
    

      
      

        
Long-press the home screen to enter jiggle mode. Drag every icon off one page — they stay in App Library. Then + → Quiet → add the small or medium widget.

        
Medium is worth it: a small widget is a single tap target, so rows are not individually tappable at that size.

      

    

  


  

    
    

      
      

        
Still in jiggle mode, tap the row of page dots near the bottom. Untick every page except the widget one. Done.

      

    

  


  

    
    

      
      

        
Drag the four dock apps up into the page area, then off it. An empty dock is much less of a pull than four bright icons sitting under your thumb.

      

    

  


  

    
    

      
      

        
Settings → Wallpaper → Add New Wallpaper → Colour → black → Set.

        
For a text-based one, make a black PNG with a line of text in any editor, save it to Photos, then Add New Wallpaper → Photos.

      

    

  


  

    
    

      
      

        
Settings → Focus → + → Custom → name it Quiet. Then under the Home Screen section, Customise Pages → select only your widget page.

      

    

  


  

    
    

      
      

        
Shortcuts → Automation → + → Focus → Quiet → Is Turned On → Run Immediately → add action Set Dumb Phone Mode → On.

        
Add the mirror automation for Is Turned Off, set to Off. Now one Focus toggle changes the home screen and the shields together.

      

    

  






  
What this still will not do

  
    
    
  • Shielded apps keep their icons. The shield appears after you tap one — there is no API to hide or remove an icon.
    • 
    
  • They can still notify you. Notification filtering is closed to third-party apps; the Focus does that part, not Quiet.
    • 
    
  • Everything stays reachable from App Library and Search. The bare page is a speed bump; the shield is the part with teeth.
    • 
    
  • Settings → Screen Time → Apps with Screen Time Access revokes Quiet's permission and drops every shield at once. Strict mode blocks deleting the app, but cannot stop that. Nothing on the App Store can.
    •
